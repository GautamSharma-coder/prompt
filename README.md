# Web Dev AI Prompt Book 🚀

A comprehensive, interactive collection of **103 production-ready AI prompts** across **16 categories**, crafted specifically for frontend and fullstack web developers. This tool is designed to help you write better prompts, ship features faster, and learn advanced prompt engineering techniques used by FAANG engineers.

## 🌟 Features

- **Single-File Architecture**: The entire prompt book is built as a single, lightweight `web_dev_prompt_book.html` file. No build steps, no dependencies, no server required.
- **103 Optimized Prompts**: Covering everything from semantic HTML and CSS styling to advanced system architecture and DevSecOps.
- **Copy & Paste Functionality**: One-click copy buttons for every prompt.
- **Zero-Effort Dev Section**: Dedicated sections for generating complete scaffolds, one-shot full stack features, and workflow automation.
- **Learning Tracks**: Specialized "Prompt 101" for beginners and "Advanced Prompt Lab" for experts.
- **Cheat Sheet**: A quick reference guide and powerful modifiers to append to any prompt.
- **Dark Mode UI**: Beautiful, responsive, and accessible dark-themed interface.

## 🚀 How to Use

1. Clone or download this repository.
2. Double-click the `web_dev_prompt_book.html` file to open it in your favorite web browser.
3. Browse the categories using the sidebar.
4. Click the **Copy Prompt** button on any card.
5. Paste the prompt into ChatGPT, Claude, Gemini, or your preferred AI tool.
6. Fill in the bracketed `[placeholders]` with your specific context and execute!

## 🧠 The 4-Part Prompt Formula

Every strong developer prompt follows this core structure:
1. **Role** (e.g., "Act as a senior React developer...")
2. **Context** (e.g., "I'm building an e-commerce dashboard using Next.js 14...")
3. **Task** (e.g., "Build a responsive data table component...")
4. **Constraints** (e.g., "Use TypeScript strict mode, Tailwind CSS, and include error handling.")
